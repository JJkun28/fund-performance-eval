# 输入格式与识别规则

脚本自动识别下面这些列。识别不对时，用 `--date-col` / `--nav-col` 手动指定。

## 表头

表头在前 10 行内即可。脚本找第一行同时出现“日期类列名”和“净值类列名”（且不在同一个单元格里）的行当表头，上方的标题行、数据来源说明会自动跳过。

## 日期列

- 列名含“日期”或“date”，排除成立日、到期日、申购、赎回、分红、除息、公告等日期。
- 支持日期格式、文本日期、`20240105` 这类整数，以及 Excel 日期序列号。
- 日期或净值为空、净值 ≤ 0 的行会被剔除；同一日期保留最后一条。

## 净值列

只考虑列名含“净值”或“NAV”的列。名字里带复权、adj、收益、增长、涨跌、日期、规模、份额等词的列一律排除（例如“复权单位净值”“净值增长率”“净值日期”）。

**单位净值**（默认）按优先级取：

1. 列名正好是 单位净值 / 净值 / 基金净值 / 产品净值 / NAV / Unit NAV（忽略空格和括号里的单位，“净值(元)”算作“净值”）
2. 列名含“单位净值”或“unit nav”
3. 其他含“净值/NAV”的列

同一优先级有多列时取靠前的。

**累计净值**（`--use-accum`）：列名同时含“累计/accum/cumulative”和“净值/NAV”。找不到时回退单位净值，并写进备注。

运行时会打印每只产品实际用的净值列。

## 基准文件

- 日期列规则同上。
- 取值列只在“大部分是数字、且不是常数”的列里选，排除代码、code、名称、简称、ticker、证券、编号等标识列（指数代码 000300 也是数字，但每行都一样）。
- 优先级：列名含收盘 / close / 点位 → 含净值 / NAV / 指数 / 价格 / price / value → 第一个可用的数值列。
- 运行时会打印实际用的基准列。

## 产品名与输出文件名

- 产品名：文件名里从第一个中文字符到“X号”（X 为阿拉伯或中文数字），其次到“X期”；都没有时，去掉“原始数据/净值数据/数据/净值”后缀。例如 `大鹏9号原始数据.xlsx` → `大鹏9号`。
- 文件名含“绩效评估”的视为输出文件，自动跳过。
- 输出文件名为 `<产品名>绩效评估.xlsx`。同一批里重名（包括只有大小写不同，或产品名恰好是“基金汇总”与汇总表撞名）时，自动改名为 `<产品名>(2)`，并写进备注。
