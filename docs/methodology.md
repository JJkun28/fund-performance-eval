# 指标口径

所有指标都以 Excel 公式写在输出文件里。下面是公式对应的口径，Python 侧（`scripts/fpe_core.py`）与之逐项一致，`tests/test_excel_recalc.py` 会用真实 Excel / LibreOffice 重算核对。

记号：`P₀…Pₙ` 为区间内各净值日的净值，`rₜ = Pₜ/Pₜ₋₁ − 1` 为期收益率，`D` 为首尾自然日天数，`k` 为年化系数，`rf` 为年化无风险利率。

## 区间与频率

| 项 | 口径 |
|---|---|
| 区间起点 | 指定 `--start` 时，往前多取一个净值日作为收益率分母（`区间` 一栏仍显示用户指定的起点之后的第一个净值日） |
| 数据清洗 | 剔除日期或净值为空、净值 ≤ 0 的行；同一日期保留最后一条；按日期升序 |
| 数据频率 | 相邻净值日间隔（自然日）的中位数：≤4 日频，≤10 周频，≤45 月频，否则季频。可用 `--freq` 手动指定 |
| 年化系数 k | 日频 252、周频 52、月频 12、季频 4。写在指标表黄色单元格里，可直接改 |
| 年化天数 | 自然日，365 天一年 |

## 产品指标

| 指标 | 公式 |
|---|---|
| 区间收益率 | `Pₙ/P₀ − 1` |
| 年化收益率（复利，默认） | `(Pₙ/P₀)^(365/D) − 1` |
| 年化收益率（线性） | `(Pₙ/P₀ − 1) × 365/D` |
| 年化波动率 | `STDEV(r) × √k`（样本标准差） |
| 最大回撤 | `min(Pₜ / max(P₀…Pₜ) − 1)` |
| 夏普比率 | `(年化收益率 − rf) / 年化波动率` |
| 卡玛比率 | `年化收益率 / |最大回撤|` |
| 索提诺比率 | `(年化收益率 − rf) / 下行偏差`，下行偏差 = `√(Σ min(rₜ,0)² / 期数) × √k`，目标收益为 0 |
| 回撤峰值日 | 最大回撤所对应的历史最高净值第一次出现的日期 |
| 回撤谷值日 | 回撤最深的日期（并列取最早） |
| 回撤修复日 | 谷值之后净值第一次回到峰值净值（≥）的日期；没回到显示“未修复” |
| 修复天数 | 修复日 − 谷值日（自然日） |

区间不足 365 天时照常年化，并在备注提示“年化指标仅供参考”。分母为 0（如没有回撤、没有下跌）时比率显示 `N/A`，回撤相关日期显示“无回撤”。

## 基准与超额

只在产品和基准**都有数据的日期**上计算；产品自身指标仍用全部净值，加不加基准不影响产品指标。

| 指标 | 几何口径（默认） | 算术口径（`--excess arithmetic`） |
|---|---|---|
| 产品归一 / 基准归一 | `Pₜ/P₀`、`Bₜ/B₀` | 同左 |
| 超额净值 | 产品归一 ÷ 基准归一 | 1 + 产品归一 − 基准归一 |
| 超额期收益 | 超额净值环比 | 产品期收益 − 基准期收益 |
| 超额区间收益 | 超额净值末值 − 1 | 同左（等于两者区间收益之差） |
| 超额年化收益 | 对超额净值末值按复利/线性年化 | 产品同期年化 − 基准年化 |
| 跟踪误差 | `STDEV(超额期收益) × √k` | 同左 |
| 信息比率 | 超额年化收益 / 跟踪误差 | 同左 |
| 超额最大回撤 | 超额净值的最大回撤 | 同左 |

## Excel 兼容性

只使用 Excel 2007 起就有的函数（STDEV、SUMSQ、INDEX、MATCH、IFERROR、COUNT、MIN、MAX）。`STDEV.S`、`MINIFS` 这类函数用 openpyxl 写入时如果没加 `_xlfn.` 前缀，Excel 打开会显示 `#NAME?`，所以这里不用。
